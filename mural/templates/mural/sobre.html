Sobre o Mini Mural

Um mural de recados construído na disciplina de Desenvolvimento WebMobile, como aplicação web em Python e Django com PostgreSQL.

Os recados ficam no banco de dados e todo usuário logado vê os mesmos. Um recado marcado como público aparece também para quem não entrou, até ser arquivado. Só quem publicou um recado pode arquivá-lo. A ordem escolhida abaixo fica guardada só neste navegador.
